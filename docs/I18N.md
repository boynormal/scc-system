# Internationalization (i18n)

Foundation สำหรับหลายภาษา — **ไม่** ใช้ URL prefix (`/th`, `/en`) คง path เดิมของแอป

## สถานะปัจจุบัน

| รายการ | ค่า |
|--------|-----|
| Library | `next-intl` |
| Locales | `th` (default), `en` |
| เก็บภาษา | Cookie `scc_locale` (path `/`, อายุ ~1 ปี, `SameSite=Lax`) |
| Messages | [`messages/th.json`](../messages/th.json), [`messages/en.json`](../messages/en.json) |
| Request config | [`i18n/request.ts`](../i18n/request.ts) |
| Config | [`i18n/config.ts`](../i18n/config.ts) |
| UI สลับภาษา | [`components/layout/locale-switcher.tsx`](../components/layout/locale-switcher.tsx) (Header + หน้า login) |
| Nav resolve | [`shared/navigation/translateNav.ts`](../shared/navigation/translateNav.ts) — `label` ใน registry = message key |

Namespaces: `common`, `ui`, `locale`, `auth`, `header`, `nav`, `transport`, `settings`, `notifications`, `apps`, `dashboard`

## สถานะคลัสเตอร์ (rollout)

| คลัสเตอร์ | สถานะ | หมายเหตุ |
|-----------|--------|----------|
| Auth (login) + Header chrome | done | Wave 1 |
| Nav / launcher labels | done | Wave 2 — ทุกป้ายเมนูรวมรายการที่เลื่อนเนื้อหาหน้า |
| Transport (titles / empty / primary CTA) | done | Wave 3 — รายละเอียดตาราง/สถานะบางจุดอาจยังไทย |
| Settings + notifications + apps shell | done | Wave 4 — hub/list titles; รายละเอียดฟอร์มบางจุดอาจยังไทย |
| Machines / maintenance / work-orders / reports | **deferred** | โมดูลซ่อมบำรุงยังไม่เสร็จ |
| HR personnel / attendance | **deferred** | บุคลากรและเวลายังไม่เสร็จ |
| Spare parts / inventory | **deferred** | คลังอะไหล่ยังไม่เสร็จ |

## วิธีใช้งานในโค้ด

Client component:

```tsx
"use client"
import { useTranslations } from "next-intl"

const t = useTranslations("ui")
return <p>{t("loadingTitle")}</p>
```

Server component:

```tsx
import { getTranslations } from "next-intl/server"

const t = await getTranslations("common")
```

Provider อยู่ที่ [`app/layout.tsx`](../app/layout.tsx) — `<html lang={locale}>` ตาม cookie

## เพิ่มภาษาใหม่

1. เพิ่มรหัสใน `locales` ที่ [`i18n/config.ts`](../i18n/config.ts)
2. คัดลอก `messages/th.json` → `messages/<code>.json` แล้วแปลค่า (คีย์ต้องครบเหมือนกัน)
3. เพิ่มป้ายชื่อใน namespace `locale` ของทุกไฟล์ messages (รวมภาษาเดิม)

ไม่ต้องย้ายหน้าไปใต้ `app/[locale]/...` สำหรับโมเดลนี้

## เพิ่มสตริงใหม่

1. ใส่คีย์ใน **ทุก** ไฟล์ภายใต้ `messages/`
2. เรียกผ่าน `useTranslations` / `getTranslations`
3. หลีกเลี่ยง hardcode ข้อความที่ผู้ใช้เห็นใน UI ใหม่ (ยกเว้นข้อมูลจาก DB / ชื่อแบรนด์)
4. ป้ายเมนู: ใช้ `key` ของโหนดใน [`moduleRegistry.ts`](../shared/navigation/moduleRegistry.ts) เป็นคีย์ใต้ `nav.*`

## ข้อจำกัด

- ข้อความจาก API / `lib/client-fetch.ts` ยังเป็นไทยเป็นหลัก — ชั้น UI ควร map `code` → `t()` เมื่อขยายต่อ
- หน้า deferred ยัง hardcode ไทยในเนื้อหา (แต่ชื่อในเมนูแปลได้แล้ว)
- ไม่รองรับ RTL ในรอบนี้
- ไม่ผูกภาษาต่อ user ใน DB (cookie พอ)

## ตรวจเร็วๆ

1. Login หรือ dashboard → สลับภาษาที่ Header / มุมบนหน้า login
2. `document.cookie` มี `scc_locale=en` (หรือ `th`)
3. รีเฟรชแล้ว `<html lang>`, เมนู, login, transport/settings titles เปลี่ยนตามภาษา
4. URL ยังเป็น `/transport/repairs` ฯลฯ ไม่มี `/en/...`
