# Module: `raw_material_news`

ข่าวสารวัตถุดิบ (กระดาษ, เหล็ก, โลหะมีค่า, Ewaste) — หน้า UI ที่ `app/(dashboard)/raw-material-news/**`

## กระดาษ (`/raw-material-news/paper`)

ดึงข้อมูลสดตอนเปิดหน้าผ่าน `GET /api/raw-material-news/paper` (auth + `raw_material_news:read`)

| บล็อก | แหล่ง | Cache |
|-------|--------|--------|
| อัตราแลกเปลี่ยน USD/RMB ต่อบาท | [open.er-api.com](https://open.er-api.com/v6/latest/USD) + ประวัติ 30 วันจาก jsDelivr currency-api | 1 ชม. |
| ราคา/ดัชนี Wastepaper จีน | HTML สาธารณะ [Sunsirs prodetail-1254](https://www.sunsirs.com/uk/prodetail-1254.html) | 6 ชม. |
| กราฟ Wastepaper | รูปจาก [graph.100ppi.com id=1254](https://graph.100ppi.com/?w=900&h=420&c=p&id=1254&state=english) โหลดในเบราว์เซอร์ (`<img>`) | อัปเดตที่ต้นทาง |
| ค่าระวาง FBX02 | [WordPress REST](https://www.freightos.com/wp-json/wp/v2/pages?slug=fbx-02-north-america-west-coast-to-china) ของหน้า [Freightos FBX02](https://www.freightos.com/enterprise/terminal/fbx-02-north-america-west-coast-to-china/) — parse JSON ที่ฝังใน `content.rendered` | 6 ชม. |

Fetch timeout **30s** ต่อแหล่ง, route `maxDuration` 60s, `Promise.allSettled` — บล็อกที่พังไม่บล็อกบล็อกอื่น

## ข้อจำกัด

- กราฟแนวโน้มใช้รูปจาก 100PPI (`<img>` ฝั่งเบราว์เซอร์) ไม่ scrape และไม่ใช้ Recharts — ถ้าโหลดรูปไม่ได้ให้มี fallback + ลิงก์ต้นทาง
- หน้า Sunsirs สาธารณะให้ **spot price** ไม่ใช่ดัชนีดีมานด์แยก — ดัชนีราคาคำนวณจากชุดที่ดึงได้ (ฐาน 100 ที่จุดแรก)
- Freightos กราฟสมาชิก Terminal ดึงไม่ได้ — หน้านี้โชว์ Current FBX + Volatility + กราฟรายสัปดาห์สั้นจาก JSON ที่ฝังในหน้าสาธารณะ (WP REST) โครงสร้างเพจเปลี่ยนได้
- HTML ต้นทางเปลี่ยนโครงสร้างได้ — UI ต้องแสดง error + ลิงก์เปิดต้นทาง
- ยังไม่มีตาราง Prisma / CMS

## ราคาโลหะบนหน้าแรก (`/apps`)

ดึงตารางโลหะตารางแรกของ [Investing.com สินค้าประเภทโลหะ](https://th.investing.com/commodities/metals) ผ่าน `GET /api/raw-material-news/metals` (ต้องมีเซสชัน ไม่ล็อกด้วย `raw_material_news:read`)

| ฟิลด์ | ความหมาย |
|-------|----------|
| ล่าสุด | ราคาล่าสุดของสัญญานั้น |
| เปลี่ยน / % เปลี่ยน | ผลต่างรายวันจากตารางราคา |
| เวลา | เวลาที่ต้นทางแสดงบนแถวนั้น |

แคชในหน่วยความจำของโปรเซส **60 วินาที** ผู้ใช้ทุกคนใช้สำเนาเดียวกัน `fetch` ของ Node ถูกหน้านี้ตอบ 403 จึงดึงผ่าน `curl` ซึ่งได้ตาราง HTML การ์ดหน้าแรกเปิดที่แผงราคาก่อน แล้วเลื่อนสลับกับนาฬิกาและสภาพอากาศทุก 60 วินาที ถ้าดึงรอบถัดไปไม่สำเร็จ การ์ดคงตัวเลขชุดล่าสุดไว้

อัตราบาทต่อดอลลาร์ด้านซ้ายของการ์ดนี้คืออัตราซื้อถัวเฉลี่ยเงินโอนของ USD จากไฟล์รายวันที่ธนาคารแห่งประเทศไทยเผยแพร่ผ่าน [thaifxrates.net](https://www.thaifxrates.net/ER_CSV_TH.zip) ซึ่งลิงก์อยู่บน [หน้าอัตราแลกเปลี่ยนประจำวัน](https://www.bot.or.th/th/statistics/exchange-rate.html) คอลัมน์ในแถว `USD` คือซื้อตั๋วเงิน ซื้อเงินโอน และขายถัวเฉลี่ย การ์ดใช้ค่าซื้อเงินโอน ไม่ใช้บรรทัดถัวเฉลี่ยถ่วงน้ำหนักระหว่างธนาคาร แคช **6 ชั่วโมง** วันที่บนการ์ดเป็นวันที่ในชื่อไฟล์ ชิปโลหะด้านขวาแสดงเป็นบาทต่อกิโลกรัมด้วยอัตราซื้อเงินโอนนี้ ตันหาร 1,000 ทรอยออนซ์หาร 0.0311035 และปอนด์หาร 0.453592 ทองแดงที่ราคาดิบต่ำกว่า 100 เป็นสัญญาปอนด์ นอกนั้นเป็นตัน เปอร์เซ็นต์รายวันไม่แปลง ถ้ายังไม่มีอัตราบาท ชิปแสดงราคาดิบเดิม

## ข้อจำกัดของราคาโลหะ

- เป็นราคาฟิวเจอร์สจากตารางแรกเท่านั้น ไม่รวมฟิวเจอร์สสหรัฐและ EUREX ส่วนใหญ่เป็นดอลลาร์ และอาจหน่วงเวลา
- Investing.com ไม่มี API เปิดให้ใช้ โครงสร้าง HTML เปลี่ยนได้ — การ์ดแสดงข้อความโหลดไม่ได้พร้อมลิงก์ต้นทาง
- หน้าเหล็ก / โลหะมีค่า / Ewaste ยังไม่มี application service ของตัวเอง
